# Smart Campus Maintenance and Complaint Management System

**Adama Science and Technology University**  
Department of Computer Science and Engineering  
Capstone Project – 5th Year, Section 1

## Project Description

A web-based system that allows students and staff to report campus maintenance problems, supervisors to assign work to technicians, and all parties to track the status of complaints in an organized way.

## Tech Stack

- **Frontend**: React + Vite + Tailwind CSS
- **Backend**: Node.js + Express
- **Database**: MongoDB
- **Authentication**: JWT + bcrypt
